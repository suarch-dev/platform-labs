# Python for DevOps Labs

This directory contains my foundational Python exercises, focused on automating system tasks, handling files, and interacting with APIs. 

## 📂 Directory Structure

*   **01-basics**: Variables, data types, printing, and basic casting.
*   **02-flow_control**: Conditional logic (`if/else`), booleans, lists, and list methods.
*   **03-loops**: Iteration (`for`, `while`), ranges, and functions.
*   **04-apis**: Consuming REST APIs using the `requests` library (GET and POST methods), handling JSON data, and error checking.
*   **05-systems**: Interacting with the OS using the `subprocess` module, parsing system command outputs (`df -h`), and implementing error handling (`try/except`) and logging.

## 🎯 Key Concepts Learned
*   Virtual Environments (`venv`) and package management (`pip`).
*   File I/O operations (`with open`).
*   API integration and JSON parsing.
*   OS-level automation and command execution.
*   Professional logging and defensive programming.
